# Callouts and Line Breaks

Obsidian callouts use semantic colors in both outputs.

> [!info] Information
> Neutral supporting information uses blue.

> [!tip] Tip
> Helpful guidance uses teal.

> [!success] Success
> Completed or successful work uses green.

> [!warning] Warning
> A warning uses a yellow background.

> [!danger] Danger
> A dangerous or destructive action uses a red background.

> [!bug] Bug
> A known defect uses magenta.

> [!example] Example
> An example uses purple.

> [!quote] Quote
> A quoted source uses gray.
